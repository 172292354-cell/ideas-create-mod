# 机械动力：奇思妙想 Mechanical Power: Ideas and More

一个基于「机械动力 Create」的 Minecraft 附属模组，围绕**下界岩的再利用**与**超稀有核心组件**两条主线展开，最终目标是锻造出无限动力的【创造马达】。

- **模组 ID**：`ideas_create_mod`
- **版本**：1.1.0
- **适用环境**：Minecraft 1.20.1 · Forge（推荐 47.x）
- **必需依赖**：机械动力 Create 6.0.8 及以上
- **强烈建议搭配**：JEI（可在游戏内查看全部配方流程）

---

## 二、核心玩法流程

### 1. 下界岩生产线：从废石到宝藏

```
下界岩 ──(滚压)──▶ 压实的下界岩 ──(粉碎)──▶ 粉碎的下界岩 ──(粉碎)──▶ 概率产物 ×10
```

粉碎的下界岩粉碎后可得 10 种产物：烈焰粉（100%）、下界合金碎片/烈焰棒/下界疣/灵魂沙/金粒/荧石粉/岩浆膏（各 50%）、恶魂之泪/下界合金锭（各 5%）。

入口也可以从 **圆石 + 100mB 岩浆搅拌** 得到下界岩。

### 2. 宝石炼金术：钻石的华丽变身

```
钻石 + 1000mB 水 ──(超加热搅拌)──▶ 紫水晶碎片
紫水晶碎片 + 100mB 岩浆 ──(机械喷嘴注液)──▶ 下界石英
下界石英 + 1000mB 岩浆 ──(搅拌)──▶ 下界石英 ×2（翻倍）
```

另可超加热搅拌：**煤炭 → 钻石**。

### 3. 序列装配：1% 的豪赌

| 产物 | 成功率 | 基底 | 装配要素 |
| --- | --- | --- | --- |
| 创造核心 | 1%（失败返还泥土） | 精密构件 | 循环 10 次：红石块→小齿轮→大齿轮→传动杆→黄铜块→下界合金块→下界之星 |
| 动力构件 | 1%（失败返还泥土） | 精密构件 | 循环 1 次：蒸汽引擎→转速控制器→小齿轮→大齿轮→传动杆→电子管 |
| 烈焰燃烧室 | 100% | 空烈焰燃烧器 | 循环 4 次：烈焰棒×2 + 250mB 岩浆注液 |

### 4. 终极目标：创造马达

收集【创造核心 ×1】与【动力构件 ×8】，在 **3×3 动力合成器** 上排列合成：

```
动力构件  动力构件  动力构件
动力构件  创造核心  动力构件
动力构件  动力构件  动力构件
```

> 该配方只能通过动力合成器完成，普通工作台无法合成。

## 三、安装

1. 安装 [Minecraft Forge 47.x](https://files.minecraftforge.net/)（1.20.1）
2. 安装 [机械动力 Create 6.0.8+](https://modrinth.com/mod/create)
3. 下载本模组 jar 放入 `mods` 文件夹（推荐同时安装 JEI）

## 四、开发与构建

```bash
gradlew runClient   # 启动开发客户端（内置 Create + JEI）
gradlew runServer   # 启动开发服务端
gradlew runData     # 数据生成（JSON 配方/战利品表等）
gradlew build       # 打包 -> build/libs/*.jar
```

环境：Java 17、Minecraft 1.20.1、Forge 47.4.10、Create 6.0.8、ForgeGradle 6。
